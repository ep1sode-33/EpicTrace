# PPTX 读取指南

## 提取

用 `extract_pptx` 工具按页提取 .pptx 内容,每页包含:
- **标题与正文占位符文本**;
- **表格** —— 行列结构尽量保留;
- **演讲者备注** —— 常有正文之外的关键信息,不要漏掉。

提取结果按页码组织,页码就是引用锚点。

## 理解叙事结构

PPT 是叙事文档,不要把它当平铺文本读:
1. 先扫一遍所有页标题,还原演示大纲(背景 → 论点 → 数据 → 结论)。
2. 摘要按大纲组织,而不是逐页流水账;数据页(图表/表格)单独核对其数字。
3. 汇报时给出页码引用(如「第 5 页的营收表」)。

## 注意

- 图片里的文字(截图、扫描图表)提取不到;用户问及某页具体图表内容时说明这一限制。
- 老格式 .ppt 不支持,遇到直接说明。
- 生成/修改 PPT 超出本 skill 范围。
