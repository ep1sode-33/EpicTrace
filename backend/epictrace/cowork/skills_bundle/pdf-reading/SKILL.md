# PDF 读取与提取指南

## 先摸底,再提取

拿到一个 PDF,先搞清楚它是什么,再决定怎么读:

1. **页数与体量** —— 决定是一次读完还是分页/分段处理。
2. **有没有文本层** —— 提取首页文本样本:能提出干净文字 → 文字型 PDF,直接提取;
   提出来是空的或乱码 → 扫描件或编码损坏,换策略(见下)。
3. **有没有表格/图片** —— 数据型 PDF(财报、论文)表格是核心内容,纯文本提取会丢结构。

在 EpicTrace 里用 `extract_pdf` 工具完成提取;它返回文本,并在可能时保留表格结构。
大文件返回会被截断——先读头几页判断结构,再按页范围继续。

## 按类型选策略

- **文字型(报告/书籍/合同)**:直接 `extract_pdf` 全文;超长文档分段提取后自行汇总,
  或派发多个子 agent 各处理一段再合并。
- **扫描件(无文本层)**:文本提取必然为空。向用户说明这是扫描件,需要 OCR;
  不要反复重试同一种提取方式。
- **幻灯片导出 PDF**:每页一张幻灯片,文本稀疏、顺序乱。按页提取,保留页码作为引用锚点。
- **数据型(大量表格)**:提取时优先保留表格的行列结构;汇总数字前先核对行列对齐是否完好,
  对不上的标注「表格结构可能有损」。
- **表单**:说明可提取字段名与当前值;不要尝试填写或生成 PDF(超出本 skill 范围)。

## 引用与汇报

- 汇总 PDF 内容时给出页码引用(如「第 3 页」),方便用户回查。
- 提取失败时把具体原因(加密/损坏/扫描件)告诉主 agent 或用户,不要编造内容。
